# MesoScope · 介孔材料合成条件抽取与检索平台

读英文化学论文，自动产出**带页码级引文**的中文结构化合成记录（12 字段），
支持跨论文检索比较与带引用问答。

---

## 1. 快速开始

```bash
# 安装 Web 层依赖（抽取内核的依赖见根目录 pyproject.toml）
pip install -r webapp/requirements.txt

# 启动（默认 http://127.0.0.1:8000）
python webapp/run.py

# 自定义端口 / 开发热重载
python webapp/run.py --port 8800 --reload
```

打开浏览器后会自动弹出**登录 / 注册**框——平台是多用户的，数据按账号隔离。
第一次使用请切到「注册」创建账号（只有用户名和密码必填，个人信息可之后补）。
弹框可以关掉，之后随时点**右上角头像**重新登录或注册。

登录后若文献库为空，点击 **载入演示数据**：会即时生成 3 篇
演示论文 PDF 并自动跑完抽取（含内容总结），**无需 API Key、无需准备 PDF**。

### 配置真实 LLM（可选）

```bash
cp .env.example .env
# 编辑 .env，填入 MKEA_LLM_API_KEY
```

填入后侧栏会显示「LLM Agent 就绪」，抽取自动切换到 anchored 模式
（全文候选 + 工具 Agent 审核），AI 问答也会从抽取式升级为生成式。
**未配置时所有功能依然完整可用**，由确定性规则引擎承担抽取。

## 2. 账号与数据归属

平台是多用户的：**先注册 / 登录才能使用**，所有数据按账号隔离保存在服务端。

| 范围 | 可见性 |
| --- | --- |
| **文献库 / 提取结果 / 样品对比 / 跨论文检索 / 任务与日志** | 只显示**自己**上传的论文与记录 |
| **AI 助手问答** | 检索**全部用户共享**的论文库，答案可引用他人上传的论文 |

这是刻意设计的不对称：个人书架是私有的，语料库是共享的。
他人论文的引文会标注「共享语料」且不可跳转原文（因为不在你的库中）。

* **跨设备共享**：个人信息与文献库都存在服务端 SQLite，换设备登录同一账号即可看到完全相同的内容。
  PDF 原文以 BLOB 形式入库，不依赖某台机器上的文件。
* **会话**：登录后服务端签发随机令牌，经 HttpOnly Cookie 下发，有效期 30 天；
  退出登录即在服务端失效。改密会使其他设备的会话一并失效。
* **密码**：`hashlib.scrypt` + 每用户随机盐，仅存哈希；校验用 `hmac.compare_digest` 定时比较。
  登录失败时「用户名不存在」与「密码错误」返回完全相同的信息，不泄露账号是否存在。
* **个人信息**：昵称、邮箱、单位、研究方向、简介，均可留空后补。
  点**右上角头像**打开账号菜单，再选「个人信息」。未登录时头像是灰色问号，点开即可登录或注册。
* **存量数据迁移**：**首个**注册的账号会自动接管升级前已有的论文（这些论文没有归属），
  之后注册的账号从空库开始。

## 3. 五个功能模块

| 模块 | 说明 |
| --- | --- |
| **AI 助手** | **首页**，整屏问答；检索全库共享语料，每条回答附页码引文 |
| **文献库** | 上传 / 拖拽 PDF（存入数据库）、自定义命名与备注、生成内容总结、选择抽取模式 |
| **复核工作台** | 左右联动：点击字段 → 跳转证据页 → 高亮原文引文；可改、可标记已复核、可导出 |
| **跨论文检索** | 按字段值关键词 + 比表面积/孔径数值区间筛选，横向比较不同论文 |
| **任务与日志** | 任务状态、所用引擎与模型、运行提示（issues） |

### 文献的命名、备注与总结

* **自定义命名**：卡片上的「命名/备注」可把显示名改成自己认得的叫法，
  `original_title` 始终保留导入时的原名，点「恢复原名」即可还原，重命名不会丢信息。
* **备注**：自由文本，显示在卡片上，也会出现在悬停速览里。
* **内容总结**：**抽取任务完成时自动生成**，不需要手动点按钮——进度条第 4 步就是「生成总结」。
  产出完整总结（弹窗查看）与一句话**简易版总结**；结果入库缓存。
  卡片上的「内容总结」用于查看，也可对尚未生成的论文（如升级前的旧数据）立即补生成或「重新生成」。
  总结失败不会导致抽取失败，只会在任务 issues 里记一条。
* **悬停速览**：鼠标**停在文献名称上**（不用点击）即弹出简易版总结，
  含论文编号、页数/记录数、自定义名与原名、一句话总结与备注。
  文献库卡片和「提取结果」的论文切换卡都支持。

总结同样是双引擎：配了 Key 由 AI 撰写，否则用确定性规则，
从已抽取字段与正文要点句组合而成（自动滤掉版权行、图注等页眉页脚噪声）。

## 4. 架构

```text
浏览器（单页，无构建步骤）
  static/index.html + style.css + app.js
        │  fetch /api/*（登录门 + HttpOnly Cookie 会话）
        ▼
FastAPI（webapp/app/main.py）
  ├─ auth             注册 / 登录 / 会话 / 个人信息
  ├─ papers / jobs    文献与异步抽取任务（按 owner_fk 过滤）
  ├─ records          复核读写与修改审计（按归属校验）
  ├─ search / export  结构化检索与契约导出（仅本人数据）
  └─ ask              带引用问答（检索全库共享语料）
        │
        ├─ auth.py         scrypt 口令哈希、会话令牌、资料校验
        ├─ extraction.py   封装现有 Agent，不重写抽取逻辑
        │     └─ mkea_extract（PDFLoader / anchored / agent / postprocess）
        ├─ heuristic.py    确定性规则引擎（无 Key 时的抽取路径）
        ├─ summarize.py    内容总结（完整版 + 悬停简易版，双引擎）
        └─ qa.py           BM25 页级检索 + 引文生成
        ▼
SQLite（webapp/data/mesoscope.db，首次启动自动建库 / 自动迁移）
  users / sessions / papers(owner_fk, pdf_blob) / paper_pages / jobs / records / edits
```

### 设计要点

**1. 不重写抽取内核。** `extraction.py` 直接 `import mkea_extract`，
复用其 PDF 解析、anchored 模式、单位归一化与证据校验。Web 层只做编排。

**2. 双引擎 + 自动降级。** 有 Key 走 LLM Agent；无 Key、调用失败或返回空结果，
自动回退规则引擎并把原因写入任务 issues。演示现场不会因网络或额度中断。

**3. 证据先校验再入库。** 任何记录写入数据库前，每条引文都要通过
`verify_evidence()` 确认确实出现在所声称的那一页，匹配失败的引文被丢弃并计入
issues——界面上看到的每个 `p.N` 都是可点击验证的。

**4. 规则引擎刻意保守。** 它只在模式命中时填值，并且：
优先读结果/实验段而非引言（避免抽到文献综述里的数值）、
拒绝把别的试剂的浓度安到当前试剂上、
排除「球形胶束」这类描述模板而非产物的句子。
抽不到就留 `null`，不猜。

**5. 演示数据走真实链路。** 载入演示数据时会用 PyMuPDF 实际生成 PDF 文件，
再经过与用户上传完全相同的解析→抽取→校验流程，而不是预埋结果。

**6. 归属校验在查询层，不在应用层。** 所有单篇接口都用
`WHERE id = ? AND owner_fk = ?` 取数据，别人的论文直接查不到（返回 404 而非 403，
不暴露该 id 是否存在）。唯一的例外是问答检索，它刻意不带 `owner_fk` 条件。

**7. PDF 存数据库而非文件系统。** 上传的字节流以 BLOB 存入 `papers.pdf_blob`，
这样账号在任何设备登录都能取到原文；解析时再临时落盘供 `PDFLoader` 读取。
升级前存在的、只有文件路径的论文仍能按旧路径回退读取。

## 5. 接口一览

### 账号

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | 注册并登录；首个账号接管存量论文 |
| POST | `/api/auth/login` | 登录，签发会话 Cookie |
| POST | `/api/auth/logout` | 退出，服务端销毁会话 |
| GET | `/api/auth/me` | 当前账号与统计（未登录返回 `{"user": null}`） |
| PUT | `/api/auth/profile` | 修改个人信息 |
| PUT | `/api/auth/password` | 修改密码（需当前密码），其他设备会话失效 |

### 数据（除 `/api/status` 外均需登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/status` | 引擎状态、本人统计、共享语料规模、字段定义 |
| GET/POST | `/api/papers` | 本人文献列表 / 上传 PDF（存入数据库） |
| GET | `/api/papers/{id}` | 详情（含记录与任务历史） |
| GET | `/api/papers/{id}/pdf` | 原始 PDF（从数据库读取） |
| GET | `/api/papers/{id}/pages/{page}` | 单页文本（供定位与高亮） |
| PATCH | `/api/papers/{id}` | 自定义命名与备注（`title` / `note` / `reset_title`） |
| POST | `/api/papers/{id}/summary` | 生成内容总结（`refresh=false` 时优先返回缓存） |
| DELETE | `/api/papers/{id}` | 删除论文及其记录 |
| POST | `/api/jobs` | 创建抽取任务（`mode`: anchored/oneshot/agent/rules） |
| GET | `/api/jobs/{id}` | 任务进度 |
| PUT | `/api/records/{id}` | 修改字段 / 标记已复核 |
| GET | `/api/records/{id}/history` | 修改审计 |
| GET | `/api/search` | 结构化检索（关键词 + 数值区间） |
| GET | `/api/export?fmt=jsonl\|csv` | 导出，JSONL 符合 `docs/extraction-contract.md` |
| POST | `/api/ask` | 带引用问答 |
| POST | `/api/demo/seed` | 载入演示数据 |

导出的 JSONL 可直接交回 `mkea-bench` 评测：

```bash
PYTHONPATH=src python -m mkea_extract.cli validate --pred predictions.jsonl
```

## 6. 测试

```bash
PYTHONPATH=src python -m unittest discover -s tests
```

全部离线，不访问网络（总结相关用例显式关掉 LLM 路径，有无 API Key 结果一致）。
`tests/test_webapp.py` 覆盖规则引擎的正确性边界
（引言 vs 结果、浓度串味、模板 vs 产物形貌、Å→nm 换算）、
证据 grounding、中文检索映射、导出契约、中文总结，
以及**账号与归属**：口令只存哈希且加盐、登录失败信息不区分账号是否存在、
会话过期与登出失效、改密使其他设备下线、各账号只能看到自己的论文、
共享语料横跨全部账号。

## 7. 已知限制

- 双向定位到**页码 + 引文高亮**，未做字符级坐标框选。
- 规则引擎每篇只产出一条记录；多样品拆分依赖 LLM 模式。
- 任务用后台线程执行，适合演示规模；高并发需换 Celery/RQ 等队列。
- SQLite 单写入者，已用进程锁串行化；PDF 以 BLOB 入库，语料很大时应改为对象存储。
- 会话 Cookie 未开启 `secure` 标志，适用于本地 HTTP；公网部署需置于 HTTPS 之后并打开该标志。
- 共享语料目前对全部登录用户开放，没有更细的授权分级或论文撤回机制。
